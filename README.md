# GIRA · site

Protótipo do site da GIRA: home com a barra Brownie de Cacau, caixas, assinatura **GIRA todo mês**, sacola e checkout simulado.

## Como abrir
Abra o `index.html` no navegador. Não precisa instalar nada.

## Estrutura
- `index.html` — página completa (HTML, CSS e JavaScript)
- `assets/` — fotos de embalagem e display

## Observações
- Embalagens, valores nutricionais, preços e sabores são ilustrativos.
- O checkout é uma demonstração: nada é cobrado nem enviado.
- Conteúdo confidencial da GIRA. Não compartilhar sem autorização.
